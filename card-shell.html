--- layout: default permalink: /card-shell.html sitemap: false card_shell: true --- {% comment %} The card shell: the page every card is shown in, with holes where the card goes. Jekyll builds this one page; it does not build card pages. After every Jekyll build the engine (kipukas-server/src/site.rs, started by _plugins/card_pages.rb) fills a copy of the shell for each card and writes it to the card's address. The shell itself is not written to the site. The holes: [[card.head]] title, description, address and structured data (in _layouts/default.html) [[card.slug]] the card's slug, e.g. brox_the_defiant [[card.image]] the file name of its art [[card.landscape]] true or false: is the art wider than tall [[card.panel]] the card's detail panel, as the engine renders it with no player state The panel is an engine-owned view (assets/js/kipukas-view.js): in the browser it is rendered again from the same code with the player's state (damage) and patched in place. So what is here must be what the engine renders, which is why the engine writes it. A player may have more than one copy of a card in play, each with damage of its own. Which copy the page shows is what follows the # of its address (/brox_the_defiant/#2), which the views that show a copy are given ({hash}): the panel, the fists dialog (in the toolbar), and the copies view below, which adds a copy, turns to the next and takes one out (kipukas-server/src/game/copies.rs, src/routes/copies.rs). Anything that differs between cards must come through a hole. The build fails if a hole is missing, misspelled, or left unfilled. {% endcomment %}
